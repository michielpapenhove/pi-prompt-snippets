# Changelog

## [0.1.0] - 2026-11-13

Initial release.

- `alt+s` overlay with search, tickable selection, and two attach modes (editor text, next prompt).
- Snippets from `PI_SNIPPETS_DIR`, default `~/.pi/agent/snippets`, grouped by top-level folder.
- Bundled starter library, copied to the snippets directory on first use.
- `PI_SNIPPETS_SHORTCUT` to move the shortcut on a key conflict.
