# Changelog

## [0.1.0] - 2026-11-13

Initial release.

- `alt+s` overlay with search, tickable selection, and two attach modes (editor text, next prompt).
- Snippets from the `prompt-snippets.dir` setting, default `~/.pi/agent/snippets`, grouped by top-level folder.
- Bundled starter library, copied to the snippets directory on first use.
- `prompt-snippets.shortcut` to move the shortcut on a key conflict.
- `PI_SNIPPETS_DIR` and `PI_SNIPPETS_SHORTCUT` environment overrides for one-off runs.
